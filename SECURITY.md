# Security Policy

## Reporting a Vulnerability

AirVPN maintains a dedicated vulnerability disclosure policy and bug bounty programme, covering
Eddie and AirVPN's other software and infrastructure:

**https://airvpn.org/security_policy/**

Please report security issues privately to **security@airvpn.org**, encrypted with AirVPN's
published PGP key:

**https://airvpn.org/static/keys/pgp_security_airvpn.txt**

Do not report security vulnerabilities through public GitHub issues.

See the full policy linked above for scope, responsible testing guidelines, and the disclosure
process.
